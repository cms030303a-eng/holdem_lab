# 홀덤 랩 — 아이폰용 웹앱

이 폴더 전체를 인터넷 주소 하나에 올리면, 아이폰에서 앱처럼 설치해 쓸 수 있습니다. (광고 없음)

## 1. GitHub Pages에 올리기
1. https://github.com 로그인 → 저장소(holdem_lab) 열기
2. **Add file → Upload files** → 이 폴더 안의 **파일과 폴더 전부**(fonts, icons 포함)를 끌어다 놓기 → **Commit changes**
3. 처음이라면 **Settings → Pages** → Branch **main**, 폴더 **/(root)** → **Save**
4. 주소: `https://내아이디.github.io/holdem_lab/`

## 2. 아이폰에 설치 (친구 쪽)
1. 주소를 **Safari**로 열기 (처음 1번은 인터넷 필요)
2. 공유 버튼 → **홈 화면에 추가** → **추가**
3. 이후 홈 화면 아이콘으로 실행 — 오프라인에서도 열림

## 업데이트할 때
- 바뀐 파일을 같은 저장소에 다시 업로드 (같은 이름이면 덮어씀)
- `sw.js` 맨 위 `VERSION` 값이 바뀌어야 폰에 새 버전이 들어감 (Claude가 매번 바꿔 둠)
- 폰에서는 앱을 한두 번 껐다 켜면 반영

## 알아둘 점
- 기록은 각자 기기 안에만 저장 (친구 기록과 섞이지 않음)
- 아이폰은 오래 안 쓴 웹앱 데이터를 지울 수 있음 → 가이드 맨 아래 **백업 코드**를 가끔 저장
- `privacy.html` = 개인정보처리방침 (Play 스토어 출시 시 이 주소를 그대로 쓸 수 있음, 문의 이메일만 수정)
